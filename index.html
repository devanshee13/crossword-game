      🧠 A* Crossword Generation (AISC)

      This project formulates Crossword Puzzle Generation as an Informed State-Space Search Problem using the A* Search Algorithm:

      • State Representation: A 2D coordinate board of placed letters and remaining words list.
      • Path Cost g(n): The bounding box area (max_r - min_r + 1) * (max_c - min_c + 1). This drives the search toward tight, compact, aesthetic crossword grids.
      • Heuristic h(n): remaining_words * 100, penalizing unplaced words.
      • Evaluation Function: f(n) = g(n) + h(n) prioritized with a Min-Heap.
      • Black Tiles ("■"): Non-letter cells are filled with solid black blockers, honoring authentic crossword puzzle design!
